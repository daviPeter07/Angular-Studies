# Angular Studies

Repositório dedicado aos meus estudos e experimentações com **Angular**, com foco no aprendizado progressivo do framework, suas funcionalidades, arquitetura e boas práticas de desenvolvimento.

O objetivo é consolidar conhecimentos por meio de exercícios, implementações práticas e projetos, registrando a evolução dos estudos.

## Projetos

### 01. Angular Practice

**Diretório:** [`angular-practice/`](./angular-practice/)

Aplicação destinada à prática dos fundamentos do Angular, incluindo componentização, comunicação entre componentes, renderização condicional, eventos e estilização de interfaces.

**Conceitos abordados:**
- Componentes standalone
- Inputs e Outputs
- Event Binding
- Control Flow (`@if`, `@else` e `@for`)
- Estado e interatividade
- Integração com bibliotecas externas

A documentação detalhada dos conceitos, exemplos e implementações está disponível no [README do Angular Practice](./angular-practice/README.md).
